# Procurement Agent

## Description
The Procurement Agent is an intermediate-level AI-powered system designed to assist with supplier sourcing, price comparison, vendor evaluation, and purchase decision support. It automates common procurement tasks to improve efficiency and reduce manual effort.

## Features
- Supplier search and comparison
- Automated price analysis
- Vendor evaluation based on predefined criteria
- Purchase recommendation generation
- Simple conversational interface for procurement queries

## Tech Stack
- Python
- LangChain / OpenAI API
- REST APIs
- Vector Database (FAISS / Chroma)
- GitHub

## Installation
1. Clone the repository
2. Install dependencies using `pip install -r requirements.txt`
3. Add API keys in environment variables
4. Run the main application file

## Usage
- Input procurement requirements (product, budget, constraints)
- The agent retrieves supplier data
- Compares vendors and prices
- Outputs a recommended procurement decision

## Future Improvements
